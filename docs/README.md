## 本版的边界

- 完成发布到归还，保留文字和图片 AI 辅助填写。
- 匹配先做规则排序，语义向量作为加分扩展。
- 没有持久任务、复杂租约、消息中心、大型 OpenAPI 和服务图。
- 不要求生产级并发和故障恢复，但保留基本权限、事务与防重复认领。

旧方案见 [归档说明](../archive/README.md)。旧接口、状态和文件路径不再作为当前要求。

当前仍是设计阶段，没有实现或实测完成的声明。

## 查问题时看哪里

| 要确定的事情 | 以哪份为准 |
|---|---|
| 字段长度、状态和隐私 | 01 功能与规则 |
| 谁改哪个文件 | 02 分工与文件 |
| 表字段、锁与事务 | 03 数据库 |
| HTTP 路径、请求和响应 | 04 接口 |
| 页面按钮、AI 和评分 | 05 小程序与 AI |
| 内部 Python 函数对接、开发顺序与验收 | 06 开发与验收 |

主要设计仍为六张表、七个小程序页面、32 个 HTTP 接口。18 个验收用例是待执行清单。修改跨模块约定时，同步相关文档，并运行 node scripts/check-docs.mjs；该检查不代表程序已经实现。
