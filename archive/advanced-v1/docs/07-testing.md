# 测试与验收

本文件帮助四人按场景验证系统。先看用例，再按权限和指标检查；不要求一开始读完全部测试细节。

> 当前为待执行计划，没有业务实现，不能将这些用例记作已通过。

术语参考：[幂等、租约、P95 与 Recall](10-glossary.md)。

## 1. 测试层次

A 组织学生端与真机联调，B 负责业务规则和事务，C 负责 AI 与任务，D 负责平台权限和部署。各人编写自己的模块测试。

- 领域单元测试：状态转换、评分与时间精度规则。
- 数据库集成测试：事务、并发接受、幂等、版本与租约；使用 MySQL 验证，不能仅靠内存数据库替代锁行为。
- API 测试：身份、对象级授权、错误码、附件用途。
- 小程序真机验收：网络、上传、生命周期与表单恢复。
- AI 固定样本评测：真实服务与模拟适配器分开记录。

不为简单页面布局编写重复实现的测试；优先验证有业务风险的规则。

## 2. 核心验收用例

用例编号保持固定。每项指定一个主责人，负责组织复现、记录结果；涉及多个区域时由对应负责人配合，不表示共同维护同一文件。

| ID | 场景 | 预期 | 主责 |

| AT-02 | 无照片无 AI 发布 | 创建成功，字段正确，可搜索 | A |

## 3. 权限矩阵

| 对象 | 访客 | 发布者 | 申请人/线索作者 | 管理员 |
|---|---|---|---|---|
| 正常公开帖子 | 读 | 读/合法编辑 | 读 | 管理读取 |
| 已下架帖子 | 不可见 | 受限历史 | 按相关业务最小读取 | 管理读取 |
| 认领证明 | 不可见 | 招领发布者可读 | 本申请人可读 | 第一版无原始证明入口 |
| 私密线索 | 不可见 | 寻物发布者可读 | 本线索作者可读 | 第一版无原始线索入口 |
| 交接联系方式 | 不可见 | 仅相关阶段 | 本人自身或相关阶段 | 第一版不开放 |
| 提取任务 | 不可见 | 不因帖子身份取得 | 任务本人可读 | 运维摘要，不默认完整内容 |

## 4. 评测与性能记录

每次评测记录以下信息，未实测的项目留空：

- 样本版本、模型和算法版本。
- 规则或混合模式、候选数量。
- Recall@5、无正例时的误推荐。
- 平均与 P95 延迟、调用量和可获得的费用。

常规接口 P95 < 1 秒为初始目标；需记录样本量、数据库规模、服务器配置、并发和网络口径。AI 接受请求与后台完成耗时分开统计。
