# 验证资料

此处存放跨端验证资料；Java 自动化测试在 backend/src/test 中。当前模板不表示测试已执行。

| 目录 | 主维护人 | 内容 |
|---|---|---|
| miniprogram/ | A | 页面交互、前后台恢复、真机结果 |
| api/business/ | B | 信息、认领、消息接口用例 |
| api/intelligence/ | C | AI、任务、匹配接口用例 |
| api/platform/ | D | 登录、文件、管理接口用例 |
| fixtures/business/ | B | 虚构业务样例 |
| fixtures/intelligence/ | C | 匹配与任务样例 |
| fixtures/platform/ | D | 字典与测试身份样例 |
| ai-evaluation/ | C | 标注合同、样本、评测结果 |
| acceptance/ | A 组织，各人填记录 | 整体流程证据与模板 |

每个人验证自己的实现。A 组织真机完整演示，B 负责业务一致性，C 负责 AI 与任务，D 负责平台与部署。

参见 [测试计划](../docs/07-testing.md)。
