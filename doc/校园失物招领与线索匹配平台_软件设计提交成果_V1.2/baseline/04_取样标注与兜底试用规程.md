# 配对样本取样、标注与人工检索试用规程

版本：QP-1，对应需求V1.2第6.5节；编写日期：2026-10-14。责任主体和数据获取尚待试点授权，本文件是操作规程，不是已完成采样报告。现有CSV均只有表头。

## 1 人员、输入与进入条件

采集负责人（作者xx或学校指定人员）负责授权/同意、数据最小化与候选池；标注员A/B为不同人员，各自独立看匿名证据并锁定结论；裁决员C为不参与A/B标注的第三人；评估操作员使用冻结版本运行算法；试用主持人与5名未参与设计的校内试用者分离。个人课程作业仍由作者独立完成，这些是将来采样的涉众角色，不声称本轮已经组成小组。

真实来源可选：获学校许可的历史登记及双方实物核验回执；或试点中由双方同意提供的寻物/招领配对记录。只把双方实物核验一致且无未决归属争议的同一实物视为配对。单方声称、算法高分或仅管理员猜测都不构成真值。无真实配对时可用人工构造集练习流程，但runKind必须SYNTHETIC，禁止用于通过A4。

先冻结采集窗口、校区、规则版本、检索库快照和样本种子，写入本次运行登记；至少需每类别10组且有足够100组不同实物。不足时报告不足并维持SEARCH_FIRST，不临时编造或放宽条件。各类别以LOST.category分层，CARD/KEY/ELECTRONIC/BOOK/CLOTHING/OTHER共6层。

## 2 采集与匿名化（逐组执行）

1. 取得记录处理许可和当事人同意，仅记录consentRef（离线凭证随机号）。采集原始记录及核验依据放在负责人批准的受限位置，不放课程提交ZIP；记录sourceKind、sourceRef、capturedAt和权限依据，不索要证件号码。
2. 取算法输入快照：双方完成核验后才能确认真值，但评分输入必须是首次认领/选定之前的同一快照，LOST及目标FOUND当时均满足B-01。不得把后来补全的正确颜色/时间倒填。历史目标如今已RETURNED时在离线快照重放当时的OPEN及expiresAt，不能直接放入当前在线搜索。其余检索库也取同一时点，最多10000条有效对向记录。
3. 用本次数据集专用随机映射生成queryId、targetId、pairToken（同一实物的匿名组号）及用户UUID。映射与真值证据只由采集负责人受限持有，与开发和提交包隔离；不是直接用学号哈希。删除姓名、联系方式、证件、图片EXIF/人脸/文字隐私。评分只保留category/color/locationCode/事件区间、校区、匿名发布者、状态标志和必要排序字段；文本检索试用只用脱敏的普通物品文本，无独有核验答案。
4. 时间整体平移同一个固定偏移量（整数据集一致且不改变间隔），包含事件、发布、截止和评估时钟；必须保持≤72小时、相交边界、有效期及排序。地点统一映射到区域字典，颜色UNKNOWN/类别OTHER和真实错误字段保留，不替算法纠错。开放样本库不得含真值targetId标签，标签仅存在评估操作员的隔离表。
5. 在候选池登记sampleId、pairToken、queryId、targetId、category、snapshotRef、sourceKind、sourceRef、consentRef、eligible、exclusionReason、split。拒收理由只用缺同意/无法确认真值/快照缺失/B-01资格不符/重复实物等固定分类；颜色类别错误或低分不得作为拒收理由。所有拒收和撤回记录计入流程统计但不充当算法空候选。

权限不足或当事人撤回时停止使用并记录排除原因。匿名化本身不证明无法重识别；提交课堂作业仅交规程、匿名汇总和必要例子，原始真值不随包公开。

## 3 可复现取样与防止挑选结果

采样前登记runId、seed、采集窗口、开发集/验收集/恢复集标识和候选池SHA256；把seed和runId冻结到运行登记，后续不能按结果换seed。

对每条eligible且标注已裁决的候选，计算排序键SHA256(UTF-8的seed + 换行 + sampleId)，同键按sampleId升序。每层取前10组，再从未选中的全部合格样本取40组：按各层剩余数量比例分配40个名额，先向下取整，剩余名额按小数余数降序分配（并列按类别代码升序），层内仍按固定排序键取。若某层余量不足，候选池不足，先扩充采集并登记新候选池版本，不能以结果差为由换样本。冻结的100组须包含全部选择依据和候选池摘要，任何人可据种子/池版本重选。

同一pairToken不得在同一集重复，也不得横跨开发、首次验收和恢复验收集；同一人不同实物可以入池。拆分时以pairToken为组先分开发/留出池；确定split后再分层选样。操作员在冻结100组以前不得计算候选排序。后续改变规则不能在同一验收集反复调参并宣称恢复达标；按6.5使用新独立100组。

## 4 双人标注与分歧裁决

A/B各自读取匿名化来源材料及双方核验回执，不能看另一人结论或算法候选；独立填写labels_a.csv/labels_b.csv：sampleId、annotatorId、decision=MATCH/REJECT/UNCERTAIN、targetId（MATCH时必填UUID）、reasonCode、evidenceRef、lockedAt（带时区ISO 8601）。输出后锁定并计算SHA256。

两人MATCH且targetId相同才直接通过；decision不一致、target不同、任一UNCERTAIN均为分歧。C填写adjudications.csv：sampleId、adjudicatorId、decision、finalTargetId、reason、evidenceRefs、decidedAt及A/B锁定文件版本。裁决员与A/B不得同人；MATCH须有真值支持，无依据则UNCERTAIN并排除、不用多数猜测。记录分歧数、排除数和原因；低分本身不得改变MATCH真值。裁决后按第3节重新冻结有效样本，补样来自同层预排序的下一条，并记录被替换sampleId。

归档清单必须保存：运行登记、合格/拒收池摘要、A/B原表和SHA256、裁决表、补样表、选中100组、匿名快照版本、脱敏检查人/时间。来源真值受限核查，不以公开核验提示供算法使用。映射表、快照和证据引用按原数据6.4期限或许可期限的较早者清理；采样不另行延长原记录/证据生命周期，到期或撤回后该样本退出未冻结池，冻结评估受影响则登记数据版本失效并重新采集。只含不可识别分子分母与规则版本的汇总可单独保留，禁止借评估归档永久保存私密附件。

## 5 盲测与失败样本归档

评估操作员按快照复现MR-1和第6.3节排序，冻结输出后才能合并target标签。samples.csv记录每组sampleId/queryId/targetId/pairToken/category/labelA/labelB/finalLabel/finalTargetId/adjudicatorId/split/snapshotRef/sourceRef/evidenceRef/consentRef；labels_a/b和裁决原表必须可独立对账。candidates.csv记录sampleId、rank、candidateId、score、partC/partK/partL/partT、ruleVersion。空候选不写候选行，由samples保留查询行，不删样本。

对100组固定分母统计命中数、空候选数、类别分层结果；通过前置为真实集、双人标注锁定、原始来源可受限复查、每层≥10及检索库资格冻结。命中≥80、空候选≤10同时满足才可NORMAL。阈值40、最多10、同分排序均不可事后改。脚本可用：

```powershell
python evidence/匹配评估脚本.py --data-dir <已填写CSV目录> --run-kind REAL --output <评估结果JSON路径>
```

输入校验失败返回非零，不生成通过报告；空模板会失败。脚本只复算已给候选和真值的统计，不证明候选确由MR-1产生、受限来源真实或学校已许可；这些必须附版本/人工核对登记。可在系统实现前手算候选制作构造集，run-kind必须SYNTHETIC，脚本输出禁止真实Gate。

每条漏判/空候选填写失败归档：sampleId、ruleVersion、queryVersion、snapshotRef、candidateIds、targetScore/targetRank（没有则null）、exclusionCode（CATEGORY/TIME/B01/BELOW_THRESHOLD/OUTSIDE_TOP10/NO_OUTPUT）、关键输入字段、标签凭证ref、复核人、处置CR。不得只保留成功例或把漏判改成无真实目标。性能执行失败另记任务失败，不悄悄当成零候选；发生执行失败本次评估无效需按同一冻结集重跑并保留失败记录。

## 6 人工检索兜底与5人试用

100组目标应在同一离线快照的无附加条件F-04检索中100/100可访问；逐组记queryId、targetId、filterState、targetVisible、权限/状态检查结果。此项只证明可检索覆盖，不意味着用户3分钟一定找到。

主持人邀请5名未参与设计的校内人员，匿名P01—P05；不得由作者或设计者替代。每人从冻结快照随机分配1个目标任务（主持人掌握目标标签，参与者只看寻物公开描述），用360px手机或1280px桌面，记录浏览器版本。主持人读相同指令：“从搜索入口找出与任务线索对应的招领记录”，不提示排序/筛选答案。若是可交互原型则结果标PROTOTYPE，正式Gate须SYSTEM。

按开始点击搜索入口至参与者提交目标recordId计时，≤180秒；在180秒仍未找到终止任务。记录participantId、taskId、deviceWidth、browserVersion、startedAt、endedAt、durationSeconds、correct、assistance、systemKind、failureCode（TIMEOUT/WRONG_TARGET/PERMISSION/NO_RESULT/OPERATION）。需要主持人帮助的任务计失败，退出也计失败，不从分母删人。5人中≥4人正确、无帮助、≤180秒通过，连同100%可检索覆盖才能支持兜底Gate。全程不采真实证件或联系方式。

主持人保留匿名任务记录与失败点，负责人登记结果和CR；发生阻断时不以换掉失败试用者增加通过率。真实试用尚未执行；evidence/templates/usability.csv为空表，不能形成已通过报告。

## 7 运行报告最小字段

runId、runKind、采集/冻结/评估时间、责任人匿名ID、seed、window、poolSHA256、snapshotSHA256、规则/数据版本、开发/验收/恢复集用途、全部来源许可ref、A/B/C锁定文件SHA256、初始池数/排除/补样/最终数、类别配额、命中及空候选分子分母、失败列表、100组覆盖记录、5人任务原表及指标、当前模式与CR、待确认事项。

负责人的真实结论、日期及作者取舍应登记进03的V表，并在05填写本人意见；没有报告时A4依旧待测。
